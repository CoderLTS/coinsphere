# CoinSphere 使用手册

CoinSphere 是个人工作流系统，插件提供业务节点、数据与页面，唯一账号 coinsphere。没有用户/角色管理、权限分享或固定结果视图；有效会话可以操作个人系统，资源归属与事务保护仍生效。

## 首次登录与导航

新系统使用空 PostgreSQL 16 和内置 Vue 的 Go App，旧数据不导入。初始化步骤见[发布](runbooks/release.md)与[数据库](runbooks/database-migrations.md)。首次密码由 COINSPHERE_AUTH__BOOTSTRAP_ADMIN_PASSWORD 配置；本地默认 coinsphere，生产必须设置随机密码。账号不预置手机号、邮箱或地区等虚构资料；初始密码仅在服务器部署账号的受限文件中由用户自行读取，勿发到聊天或日志。登录后在个人中心改密码，全部会话失效；退出持久撤销当前会话。

初始一级菜单：首页、工作流、人工智能、量化、币安、配置管理、系统管理。AI 模型在人工智能，代理/插件在配置管理，菜单管理在系统管理。系统监控首页及 ArtDesignPro 主题、标签、表格和弹窗保持。

菜单管理可新增多级目录，选择插件普通/结果页挂载；每页最多一个入口。修改父级、名称、图标、排序、隐藏后保存，导航、面包屑与标签刷新。页面地址不随层级变化。重启/升级/插件重载保持用户布局；新增页面从可选目录手工挂载。缺插件入口隐藏、配置保留，直接访问显示错误；重新加载恢复。

## 模型与助手

在人工智能配置模型端点、名称、密钥、超时和启用状态；模型端点可为用户明确配置的公网或内网 HTTP/HTTPS，不跟随重定向。密钥加密保存只显示掩码。AI 模型调用节点选择 modelId，结构化输入/输出保留；模型配置修改只影响后续调用，停用/删除时明确报错。

AI 插件加载后顶栏显示智能助手；缺插件不显示入口。助手可查询平台/插件数据、生成未发布且停用的草稿；用户在编辑器检查后手工发布、激活或运行。流式会话在登出或改密后停止，不继续持久写入。

## 创建、发布和运行

1. 工作流定义创建，填写名称/描述，选模板或从加载的插件节点编排。
2. Config 放静态值；输入绑定选择固定 JSON、入口 input、节点输出或 CEL。金融金额/数量使用十进制字符串，时间为 UTC。
3. 编辑 main/其他入口、事件类型、Loop 子图。显式表达式如 nodes["check"].ready，不隐式合并同名输出。
4. 保存生成新草稿修订，metadata/Secret 同事务；发布修订不变。过期编辑指针冲突时刷新后再应用。
5. 发布校验图、插件及必要凭据。手动运行选择修订/入口/JSON，可试未发布草稿；自动触发只使用发布修订，激活需要用户操作。
6. 停用停止自动入口，取消操作针对具体 Run。历史修订只读；新修订有独立持久状态，有状态工作流串行执行。

Secret 只显示是否配置，新值替换、留空保留、显式移除；不写入图或结果。配置 Connector 前指定允许的精确公网域名，默认拒绝外部目标。

## 插件组合与结果

可组合采集 → AI → Notification；QQ 接收 → AI → QQ 回复；公共行情 → Quant 指标/策略 → Paper → 通知，或使用通用回测模板。QQ 外部收件人仍配置外部 QQ 标识；站内通知固定发送到个人收件箱，没有站内用户/角色目标。

Quant 拥有分析/回测，Binance 拥有公共行情/补数/K 线、Paper 与导出。结果页使用当前筛选，无需创建固定视图。运行详情展示真实 Run、尝试、日志、制品与插件面板；审批在运行详情一次性通过/拒绝，过期/替代/取消不能重复决定。

waiting 表示等待处理，retrying 表示等待重试。unknown_result 表示外部结果未知，不能直接重试；先核对业务事实。诊断重放复用已有副作用检查点，不重新发送通知或产生账本副作用。Binance 当前不提供 Live 或私有账户接口。

## 生命周期与恢复

插件管理区分安装/编译/加载事实和原因。可信源码通过 CLI 安装并重建；当前定义/在途 Run 阻止升级或卸载，菜单不阻止且保留布局。卸载不删数据；purge-data 还受全部历史引用保护。

备份必须包含配对数据库、镜像、配置/加密 key 和独占文件；禁止 Down、伪造版本或删账本绕过错误。g5 用户验收前保留旧部署，验收后删除清单中的旧专属资源及恢复资料；旧状态此后不可恢复，原工作流/凭据/历史需重新配置或产生。

明确清空重建会重置个人密码、菜单和所有业务配置/历史，需要重新配置模型、代理及插件凭据；操作步骤见[数据库手册](runbooks/database-migrations.md#已部署-g5-再次重建)。普通重启或升级不会清空数据。
