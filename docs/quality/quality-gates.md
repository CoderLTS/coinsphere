# CoinSphere 质量门禁

默认不执行本地测试、构建、应用、数据库演练或浏览器验证；静态阅读、编辑和格式化完成后交远端 CI。未执行或失败的步骤不能写成通过。Ready PR 以 main 为 base；CI 全绿后主 Agent 最终只读复审。

| 门禁 | 覆盖 |
| --- | --- |
| Go | go mod tidy -diff、gofmt、go vet、go test -race ./...、go build ./...；隔离 PostgreSQL 16 与外部替身 |
| Core | 无业务插件登录/菜单/调度/运行/审批；发布冲突、租约/取消、有界池、Loop、审批并发、状态隔离、未知结果 |
| 导航 | 顶级/二级/三级、父级循环/重复页面、移动地址不变、重启/重载不覆盖、缺插件隐藏/配置保留 |
| AI | modelId、配置快照、停用/删除错误、内网 URL、密钥掩码、SSE/撤销会话、未发布停用草稿 |
| 插件与金融 | 真实依赖/贡献、资源范围/动作/事务复验、卸载活动引用、失败安装恢复、跨插件替身组合、Paper 重复订单/余额/费用/持仓 |
| 初始化 | g5 空库/重复启动、单账号/版本拒绝、Core 和插件独立账本；旧表和 Live 删除确认 |
| Vue | ESLint、类型/构建、模型测试、Playwright chromium/firefox/webkit；通用编辑/运行/审批、插件页面与顶栏、菜单刷新 |
| 发布 | 三可执行文件与归档/镜像扫描、固定 digest、候选身份持久、定向恢复/清理不影响旧部署与共享服务 |

示例插件仅 CI 装入注册表，外部请求使用替身，CI 不接触真实交易密钥。合成测试不能证明生产界面、实际外部服务、维护窗口或旧专属资源清理已完成。现场验收和恢复点按[发布](../runbooks/release.md)与[数据库](../runbooks/database-migrations.md)记录；代码交付不自动开始正式 Paper 观察。
